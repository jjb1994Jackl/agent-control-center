在 Windows 上代发消息

    
Windows 不允许程序在后台按桌面版的按钮而不让它拿到焦点。所以工作台经过桌面版的窗口代发一条消息时，那个窗口会短暂拿走焦点几次，每次不到 0.1 秒。

    
    
      
  • 这时你如果在别的程序里打字，正在拼的字可能会被打断。在工作台里打字时，它会等你停顿再动手。
    • 
      
  • 改模型或推理强度时，大约半秒内你打的字会进到桌面版里。
    • 
      
  • 前台的程序独占全屏时，消息会等你离开它再发。
    •
