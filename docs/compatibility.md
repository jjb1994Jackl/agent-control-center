# Mac 预览兼容性

预览版只发 Mac 源码安装器：Node 22.16+、npm、Apple 命令行工具。安装和服务自恢复在 Apple 芯片、macOS 26.5.2 的隔离数据目录中验证；未重启或重新登录整台 Mac。Intel、其他 macOS 版本和 Windows 尚未验收。各 Agent 还受自己的系统和账号要求限制。

| 已有适配器 | 工作台入口 | 回传与额度 | Mac 登录后台启动 | 真机证据范围 |
|---|---|---|---|---|
| Codex | 已有会话、受支持的桌面项目可新建 | 原会话与任务状态；可读取账号时间窗口 | 支持 | 既有实例验证连接和自启后的重新连接；预览须独立验收 |
| Antigravity | 已有会话、受支持的工作区可新建 | 原会话与任务状态；可按模型读取额度 | 支持 | 既有实例确认从未运行到启动、连接；预览须独立验收 |
| Grok Bot | 已有聊天及群组；主 Bot Routine 另设 | 原聊天可回读；Routine 需要编号回执，周额度由原应用读取 | 支持 | 既有实例曾真验收主 Bot 回执和一个群的收发；启动后可读取不同群组 |
| Claude | 上游适配器保留；按模式支持会话与新建 | 原会话与用量能力来自上游 | 已接入启用开关，未真测自动启动 | 当前账号不可用，不列入本轮真实收发验收 |

「支持」描述实现方式，不代表任意账号、系统版本或权限组合都通过。普通千问、千问办公、Kimi 与 WorkBuddy **当前没有适配器**，见[接入指南](add-agent.md)。
