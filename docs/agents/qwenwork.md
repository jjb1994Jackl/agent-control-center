# 千问办公 QwenWork

状态：接入指南，未开发适配器。[阿里云 Mac 安装指南](https://www.alibabacloud.com/help/zh/qwenwork/macos-install)说明 `QwenWork.app` 和两种芯片版本；[厂商桌面流程](https://help.aliyun.com/zh/qwenwork/desktop-usage)说明对话结果和交付物。验收使用自己的测试组织和账号。

1. 建议插件 ID `qwenwork`。先核对桌面端的组织、工作区和任务标识，不能只用任务标题匹配。有官方可操作同一桌面任务的通道就先验证；未核实前不假定网页版、钉钉入口或普通千问共享同一任务控制接口。
2. 验证工作台能进入已有任务，并用原生通道提交文字、回读同一任务结果。缺少任务唯一性证据时不提交。支持等待确认时只展示状态，决定仍在原应用；产物只有在原任务可见且能对上时才展示链接，不复制整个项目。
3. 真机验收分别核对受理、等待、结束和产物。使用两个独立任务回显 `QWW-A`、`QWW-B`，再用测试任务验证一个明确终态和一个不确定状态。不能仅凭最新文字、超时、产物存在就宣告完成。
