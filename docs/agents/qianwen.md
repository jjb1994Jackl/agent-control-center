# 普通千问桌面客户端

状态：接入指南，未开发适配器。入口：[千问官方下载](https://www.qianwen.com/download)。选择 Mac 桌面客户端；如果下载页提供多个版本，记录实际安装的产品、芯片架构、Bundle ID 和版本，未确认前不填猜测值。

1. 首个目标是已登录客户端的**普通聊天**。建议插件 ID `qianwen-chat`，不与 `qwenwork`、千问输入法或百炼模型 API 混用。先测试两个普通聊天的标题、消息与稳定标识能否从官方同会话入口或用户授权的 macOS 辅助功能读取。
2. 先读列表和历史，再做发送。选中会话后重新确认窗口和对话身份，遇到重复名称、草稿、未登录或无法读取回显就不发送。只验证文字，文件、模型切换与额度后续独立验证。
3. 最小验收：原客户端的两个聊天分别回显 `QW-CHAT-A` 和 `QW-CHAT-B`，工作台不串线，刷新不重发。只有普通聊天回传证据时，兼容性表不能写成支持 QwenWork 原生任务。记录实测版本、芯片、语言和不支持项。
